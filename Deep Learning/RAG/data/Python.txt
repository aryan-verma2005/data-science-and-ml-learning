In Python, textual data is primarily handled using the built-in str object (strings), while file-based text operations rely on the open() function with a text mode.Handling Text as StringsPython treats any sequence of characters inside single ('...'), double ("..."), or triple ("""...""") quotes as a string.Immutability: Python strings cannot be changed after creation; any modification generates a completely new string object.F-Strings: The preferred way to inject variables directly into text is using f-strings (e.g., f"Hello {name}").Built-in Methods: The str class provides methods like .upper(), .lower(), .split(), and .join() to process text without external libraries.
